## Description

Anikin parses website data and filter required info, thus It removes the ads for seamless experience. The app doesn't require account creation to use it.

### Features

* Search
* Recently Added
* Popular
* Movies
* Add To Favourites
* Auto Quality for Video Playback
* Ads Free Video Playback
* Online syncing of Favourite list & watched progress (requires login)

## RELEASING

Update the `version:` value in `pubspec.yaml`. The part before `+` is the
public release version, and the numeric part after `+` is the build number,
which must increase for each published build.

Create and push a tag matching the public version, such as `v3.0.9` for
`version: 3.0.9+52`. The release workflow rejects tags that do not match.
